# Путеводитель по поездке: запуск

Два файла: `index.html` (приложение) и `config.js` (настройки). Ничего собирать не нужно.

## 1. Firebase: база данных (≈5 мин)

1. https://console.firebase.google.com → открыть существующий проект (или создать новый).
2. **Build → Realtime Database → Create database** → регион `europe-west1` → **Start in locked mode**.
3. Вкладка **Rules** → вставить и нажать **Publish** (поменяйте `asia26-x9m4tq2v` на свой `tripId` из `config.js`):

```json
{
  "rules": {
    "trips": {
      "$trip": {
        ".read":  "$trip === 'asia26-x9m4tq2v'",
        ".write": "$trip === 'asia26-x9m4tq2v'"
      }
    }
  }
}
```

4. **⚙️ Project settings → General → Your apps → `</>` (Web)** → любое имя → **Register app**.
   Скопировать объект `firebaseConfig` и вставить в `config.js` вместо `firebase: null`.
   Проверьте, что в нём есть строка `databaseURL` (если её нет, возьмите адрес со страницы Realtime Database).

## 2. GitHub Pages: хостинг (≈3 мин)

1. github.com → **New repository** → имя, например `trip-2026`, **Public** → Create.
2. **Add file → Upload files** → перетащить `index.html` и `config.js` → Commit.
3. **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/trip-2026/`.

## 3. Telegram Mini App (≈3 мин)

1. Написать **@BotFather** → `/newbot` → имя и username бота (например `asia2026_trip_bot`).
2. Там же `/newapp` → выбрать этого бота → название, описание, картинка 640×360 → на вопрос про GIF ответить `/empty`
   → **Web App URL**: адрес с GitHub Pages → short name, например `trip`.
3. BotFather выдаст ссылку вида `https://t.me/asia2026_trip_bot/trip`. Её можно кинуть в групповой чат и закрепить:
   по нажатию путеводитель откроется прямо внутри Telegram, поверх чата.
4. (По желанию) `/setmenubutton` → бот → тот же URL: тогда в личке с ботом появится кнопка рядом с полем ввода.

## Как пользоваться

- **Маршрут**: всё по дням, собирается само из билетов, жилья и мест с датой. Подсвечивает ночи, на которые жильё не указано.
- **Координаты**: можно вставить «13.7563, 100.5018» или длинную ссылку Google Maps. Короткие `maps.app.goo.gl` тоже можно,
  но на карте приложения такая точка не появится: будет только кнопка «Карта».
- **Без интернета** показывается последняя загруженная версия. Изменения, сделанные офлайн, отправятся,
  когда появится связь, пока приложение открыто.
- **Резервная копия**: «Ещё» → «Скачать копию (JSON)». Стоит сделать перед вылетом.

## Про приватность

`tripId` лежит в `config.js` в публичном репозитории, поэтому данные может прочитать любой, кто найдёт сайт или репозиторий. Не храните тут
номера паспортов и карт. Коды бронирований приемлемо, но с ними можно зайти в бронь, учитывайте это.
